02 / PLATFORM

הפלטפורמה: n8n Self-Hosted

n8n היא פלטפורמת אוטומציה בקוד פתוח שתרוץ על שרת של דטוויז. היא נותנת לנו את כל היתרונות של אוטומציה ויזואלית, בלי תלות בספק חיצוני ובלי עלות חודשית.

למה n8n

חינמי לחלוטין כשמריצים על שרת פנימי.
הנתונים נשארים בתשתית של דטוויז - יתרון אבטחתי משמעותי.
גמיש לחלוטין - תומך ב-AI, בלוגיקה מורכבת, ובכל אינטגרציה אפשרית.
קוד פתוח - אין חשש משינוי תמחור או הפסקת שירות.
ללא מגבלות על מספר פעולות - אפשר להגדיל ככל שדטוויז גדלים.

03 / REQUIRED INFO

המידע הדרוש לפני התחלת הפיתוח

זו הרשימה המינימלית וההכרחית למה שצריך כדי להתחיל לעבוד. חלוקה לפי גורם.

A מאוריגמי / קומיגו חיצוני
אישור עקרוני לגישת API. אישור בכתב שדטוויז רשאים להשתמש ב-API של קומיגו לקליטת לידים.
API Endpoint URL לקליטת לידים. לדוגמה: https://api.comigo.com/v1/leads
שיטת אימות + Credentials. בדרך כלל API Key. צריך לקבל את המפתח עצמו ולהבין איך לשלוח אותו.
מבנה JSON שהם מצפים לקבל. אילו שדות צריכים להיות ובאיזה שמות. { "name", "phone", "email", "source" }
שדות חובה לעומת אופציונליים. מה חייב להיות בקריאה ומה לא.
גישה לסביבת Sandbox. כדי לבדוק בלי לזרוק לידי דמה למערכת האמיתית.
תיעוד API. PDF, לינק, או מסמך של ה-Endpoints וההגדרות.
B מהמנכ"ל / הנהלת דטוויז פנימי
אישור עקרוני לפרויקט. אור ירוק להתקדם.
החלטה איפה רץ n8n. שרת פנימי? VPS? דורש קלט מאבטחת מידע.
מי מקבל התראות וואטסאפ. מספרי טלפון של מנכ"ל, BizDev, ומי שעוד אמור לקבל, כולל הסכמתם.
שעות פעילות להתראות. האם לשלוח וואטסאפ בלילה? בסופ"ש?
אישור לעלויות AI. כ-5-15 ש"ח בחודש לניתוח לידים.
איש קשר מאבטחת מידע. מי מאשר את הפתרון ומה התהליך.
C מצד Wix (יש לך כבר) פנימי
גישת אדמין ל-Wix Editor של דטוויז.
זיהוי הטופס הראשי באתר. איזה טופס בדיוק מחברים.
רשימת שדות הטופס. שם, אימייל, טלפון, הודעה, ועוד.
תוכנית Wix נוכחית. וידוא ש-Wix Automations זמין.
D למרכיב ה-AI חיצוני
חשבון Anthropic API (Claude). פתיחת חשבון לקבלת API key.
תקציב ראשוני ל-API. טעינה של 20-50$ (יחזיק חודשים).
E להתראות WhatsApp חיצוני
מספר טלפון עסקי לדטוויז. מספר ייעודי לחברה.
הקמת חשבון Meta Business. דרוש לרישום ל-WhatsApp Cloud API.
חשוב להדגיש: ברגע שכל הסעיפים מסומנים, אנחנו מתחילים מיד. אין צורך לחכות להכל בבת אחת. אפשר להתחיל בקצוות שכבר מוכנים (Wix + n8n + AI) ולחבר את קומיגו אחרון.
04 / WORK PHASES

שלבי העבודה

חלוקה לפאזות עם הערכת זמן ריאלית. כל פאזה היא יחידה עצמאית שניתן לבדוק לפני המעבר לבאה.

01 הקמת תשתית ~2 שעות

בסיס של כל המערכת. ברגע שזה עומד, אפשר להתחיל לבנות מעליו.

  • הקמת n8n self-hosted (Docker או חשבון cloud זמני)
  • חיבור ראשוני וקונפיגורציה בסיסית
  • פתיחת חשבון Anthropic API לניתוח AI
  • פתיחת חשבון WhatsApp Cloud API
  • הגדרת סביבות פיתוח ובדיקות
02 חיבור מקור ראשון - Wix ~1.5 שעות

חיבור הטופס באתר של דטוויז ל-n8n. הצינור הראשון פועל.

  • הגדרת Webhook Trigger ב-n8n
  • הגדרת Wix Automation להפעלת HTTP Request
  • בדיקה ידנית עם 5-10 לידי בדיקה
  • אימות שכל השדות מגיעים נכון
  • טיפול ב-RTL ותווי עברית
03 לוגיקת ניקוי וולידציה ~2 שעות

השלב שמפריד בין מערכת חובבנית למקצועית. ניקוי, סינון, והגנה.

  • ולידציה של שדות חובה
  • סינון ספאם בסיסי (URLs בהודעה, מילים אסורות)
  • ניקוי וסטנדרטיזציה של מספרי טלפון
  • בדיקת כפילויות (אותו אימייל ב-24 שעות)
  • העשרת נתונים: מקור, timestamp, IP, User Agent
04 שילוב AI Agent ~2.5 שעות

החלק החכם. כתיבת prompt מקצועי שמנתח כל ליד.

  • חיבור node של Claude ל-workflow
  • כתיבת prompt מקצועי לניתוח לידים
  • הגדרת מבנה JSON של התשובה
  • בדיקות איכות עם 20 לידים מגוונים
  • שיפור ה-prompt על בסיס תוצאות
05 חיבור Comigo ~2 שעות

העברת הליד עם הניתוח לקומיגו.

  • הגדרת קריאת API מ-n8n לקומיגו
  • מיפוי שדות בין n8n לקומיגו
  • שילוב ניתוח AI כהערה בכרטיס הליד
  • בדיקה בסביבת Sandbox
  • טיפול בשגיאות + retry logic
06 התראות וואטסאפ + סלאק ~1.5 שעות

הענפים הנוספים של ההתראות במקביל.

  • הגדרת node של WhatsApp Cloud API
  • עיצוב תבנית הודעה מקצועית עם פרטי ליד + ניתוח AI
  • הוספת לוגיקת שעות שקטות
  • אופציונלי: הוספת סלאק / מייל פנימי
  • בדיקה מקצה לקצה
07 בדיקות מקיפות ~1.5 שעות

לוודא שהמערכת עובדת בכל תרחיש, כולל מצבי קצה.

  • בדיקה עם 30+ לידי דמה מגוונים
  • בדיקות כשל: קומיגו לא זמין, AI נכשל
  • בדיקת ביצועים: זמן תגובה, רוחב פס
  • בדיקת אבטחה: אימות webhooks, הצפנה
  • תיעוד באגים ותיקונים
08 תיעוד ומסירה ~1 שעה

לוודא שהמערכת תוחזק גם אחרי שנסיים.

  • תיעוד טכני בסיסי
  • מדריך תפעולי קצר
  • רשימת אנשי קשר במקרה של תקלה
  • הדרכה למי שיפעיל אחריך
סך הכל: כ-14 שעות עבודה בפועל. בסשנים של 3-4 שעות, זה 3-4 סשנים. כולל buffer לתקלות, הערכה ריאלית: 16-18 שעות.
